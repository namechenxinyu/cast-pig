  投屏猪 · 使用说明
════════════════════════════════════════

【日常使用: 两步】
  双击「投屏猪」图标 → 打开后自动扫描, 上次用过的设备会自动预选
  → 确认设备后, 点「▶ 开始投屏」
  (多台设备时可自由切换选择, 不会投错; 第一次使用需自己选一次设备和模式)

【结束投屏】
  在投屏猪窗口点「■ 停止」, 或直接关掉窗口

【换设备 / 换内容】
  点「⟳ 扫描设备」刷新列表 → 选另一台 → 选内容 → 「▶ 开始投屏」

【画面不够清晰? 先试这个】
  「输出画质」选 1280x720 —— 多数平价投影仪是 720p 原生面板, 让电脑端
  缩放比投影仪自己缩更清晰; 若还是不够, 就是投影仪光机本身的物理极限
  (这类投影常见 720p 面板+单 LCD 光机, 宣称"支持1080p"≠原生1080p)

【投视频文件】
  选「视频文件(无损+声音)」→ 选择文件 → 开始
  (视频直推画质无损, 看电影推荐用这个)

────────────────────────────────────────
【第一次使用前, 检查一次环境】
  Linux  : 需要 python3 + ffmpeg (一般都自带)
           缺 ffmpeg 时: sudo apt install ffmpeg
  Windows: 需要 Python(官网安装时勾选 Add to PATH)
           ffmpeg 缺失时启动器会问你是否自动下载(约40MB)
           想有声音: 声音设置 → 录制 → 启用「立体声混音」

【注意事项】
  · 电脑和电视/投影仪必须连同一个路由器
  · 画面延迟约 2~4 秒(DLNA 方案固有), 放演示没问题,
    需要零延迟的场合请用 HDMI 线
  · 所有数据只在局域网内传输, 不经过外部服务器
  · 投影仪上的"视频软件投屏"入口就是它自带的 DLNA 服务,
    无需安装乐播等任何第三方 App 即可使用本软件

【如果双击启动脚本提示错误或没反应】
  在终端里运行一次:  chmod +x 启动投屏猪.sh
  (从压缩包/网盘下载的文件可能丢失执行权限, 双击会打不开或报奇怪错误)
